Preparcial (20%) - Plataforma E-Commerce con Next.js y React Context

Objetivo General

Integrar conceptos fundamentales y de arquitectura en React y Next.js (App Router) para diseñar una aplicación web modular que gestione un catálogo de productos, permita la navegación fluida entre vistas estáticas y dinámicas, y mantenga un estado global compartido y persistente a lo largo de toda la experiencia de usuario, haciendo uso de:

  • Enrutamiento de vistas y layouts persistentes con App Router.

  • Manejo de estado local, efectos e interactividad en componentes de cliente.

  • Comunicación de componentes y flujo unidireccional de datos mediante Props y Callbacks.

  • Gestión y consumo de estado compartido utilizando React Context API.

  • Consulta asíncrona a servicios web externos mediante peticiones HTTP.

  • Tipado estricto de modelos y componentes con TypeScript.

Enunciado del Reto


Desarrollar la aplicación web "ShopHub", una plataforma de comercio electrónico construida sobre la arquitectura App Router de Next.js.


La aplicación debe permitir a los usuarios consultar un catálogo de artículos obtenidos de forma asíncrona, explorar la información detallada de cualquier producto mediante navegación dinámica y administrar un carrito de compras global cuyos datos se mantengan sincronizados y persistentes a lo largo de todas las vistas sin recargas completas del navegador (SPA).

Requisitos de Arquitectura y Buenas Prácticas


    

  • 

    Estado Global Compartido: Implementar un contexto de React que centralice la información de los productos en el carrito y exponga los mecanismos necesarios para agregar nuevos ítems desde cualquier nivel de la interfaz.
    

    • 

  • 

    Persistencia de Navegación: El estado global no debe reiniciarse al navegar entre el catálogo y las vistas de detalle.
    

    • 

  • 

    Inmutabilidad: Garantizar la actualización adecuada de arreglos y objetos en memoria, evitando mutaciones directas y asegurando que React detecte los cambios de estado.
    

    • 

  • 

    Modelado y Tipado: Definir contratos claros con TypeScript para los datos del producto y las propiedades que intercambian los componentes.
    

    • 

  • 

    Fronteras Cliente/Servidor: Identificar y marcar como componentes de cliente únicamente aquellos módulos que requieran interactividad, captura de eventos o hooks de estado/ciclo de vida.
    

    • 

  • Diseño de interfaz: Evitar aplicaciones sin diseño o poco usables, se recomienda en esta fase de desarrollo el dejar la aplicación lo mas organizada y visualmente adecuada posible.
